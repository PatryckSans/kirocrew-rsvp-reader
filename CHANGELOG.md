# Changelog

## 0.1.0

First release.

- One word at a time at a fixed focal point; opens from the composer chip (Quick read here), a
  side-panel tab bound to the current chat, or a full page.
- Replies-only message list (closing reply of each turn), with cleaned previews, reading time and
  hour; "All messages" one click away. A banner offers a new reply once the chat goes quiet.
- Markdown cleanup with a Settings screen (presets, per-category rules, reading display); the
  agent's `[OPTIONS: ...]` line is skipped; long words are split; numbers, versions, ids and paths
  get a longer pause.
- Remembers where you stopped in each message; shows time left; steps back a few words when you
  resume; slow start after Play.
- Position chip (`item 3/8 · title`) over the focal word inside lists, current item highlighted
  in the Context box; the Context box keeps the chat's paragraphs, lists and tables.
- Keyboard shortcuts (`[` `]`, `Alt` + arrows, `Home`, `Esc`, `?`), shortcut list, first-run tips.
- All code, comments, tests and documentation are in English (the marker-language option still
  offers Portuguese).
